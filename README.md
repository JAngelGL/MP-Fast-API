# MP-Fast-API
Use and test of fast API

### Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

### Windows:
```bash
python -m venv venv
venv\Scripts\activate
```


## Install Dependencies
```
pip install -r requirements.txt
```


## Run the API

```bash
uvicorn app.main:app --reload
```

## API will run at:

```
http://127.0.0.1:8000
```
